# Design de referência

Primeira versão visual do Meu Financeiro: seis telas (Painel `Main`, `Transacoes`, `Contas`, `Login`, `Revisar`, `Enviar`). Os arquivos `*.dc.html` são HTML com marcação própria do editor de design (`<x-dc>`, `{{campos}}`, `<sc-for>`, `<sc-if>`); **leia-os como referência de layout, textos, cores e tipografia**, não como código para copiar. A implementação é em Next.js + React + Tailwind.

O mesmo design está publicado como Artifact privado no claude.ai (Meu Financeiro), onde dá para ver e interagir.

- Títulos e valores: Bricolage Grotesque. Texto: IBM Plex Sans.
- Os números nas telas são fictícios.
- Se o design e a spec se contradisserem, o agente para e avisa o CTO.
