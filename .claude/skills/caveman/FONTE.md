## Como usar

Digite `/caveman` na sessão do Claude Code. Para desligar: "stop caveman" ou "normal mode".

## Limites neste projeto

- A skill só muda o estilo das respostas no chat. Ela mesma manda escrever por extenso tudo que fica salvo (código, commits, cartões, ADRs, PRs).
- Os aliases `/caveman ultra` e `/caveman wenyan` dependem das skills `ultracave` e `megacave`, que **não** foram instaladas.
- Para o dono, prefira o modo normal quando a explicação for nova ou difícil: o `CLAUDE.md` pede relatórios claros.
