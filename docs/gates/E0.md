# Gate E0 — Fundação (v0.0)

Quem fecha: o dono. Quem confere antes: o QA (clone limpo), o `revisor` (CI e regra de lint) e o CTO (diff contra este checklist). O código do E0 é escrito por agentes; o dono só liga as proteções do GitHub.

## Entregas

- [ ] Repositório criado, `main` protegida (feito pelo dono, T0.3b), trabalho por PR.
- [ ] `pnpm`, TypeScript `strict` + `noUncheckedIndexedAccess`, Vitest, ESLint, Prettier configurados.
- [ ] Pastas de `domain/`, `tests/fixtures`, `docs/decisoes`, `docs/gates` criadas.
- [ ] `.gitignore` cobre `.env*`, `*.csv`, `*.xlsx`, imagens, `credentials.json`, `secrets/`; fixtures fictícias liberadas só em `tests/fixtures/`.
- [ ] `.env.example` com os nomes das variáveis (seção 14 da spec), sem valores.
- [ ] `CLAUDE.md` na raiz.
- [ ] Spec v2.3 e roteiro copiados para `docs/`.

## Qualidade

- [ ] `pnpm typecheck`, `pnpm lint` e `pnpm test` passam.
- [ ] A regra de lint barra importação de I/O dentro de `domain/` (provado com um arquivo de exemplo que falha; removido depois).
- [ ] CI roda `tsc --noEmit`, ESLint, Vitest e gitleaks, e fica verde num PR vazio.

## Segurança

- [ ] gitleaks limpo no histórico.
- [ ] Nenhum dado real, print ou dump no repositório.

## Encerramento

- [ ] `CHANGELOG` criado com a entrada v0.0.
- [ ] Tag `v0.0` no Git.
- [ ] Decisões novas registradas em `docs/decisoes/`.
- [ ] Parecer do `revisor` anexado (CI e regra de lint).
- [ ] Retro curta: o que atrasou, o que mudar no E1; reestimativa do prazo pelo CTO com o ritmo real.
