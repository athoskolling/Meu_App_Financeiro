# T2.5b: Design System completo, cabeçalho evoluído, navegação inferior mobile e contratos de ViewModel

## Cartão (preenchido pelo CTO)

- **Estágio / tarefa:** Fase Visual (V1) / E2 / T2.5b (ADR-0028; também resolve o achado baixo de `:focus-visible` do PR #30 / Issue #43).
- **Equipe e agente responsável:** `gemini-dev-frontend` (`Hydrogen XHigh`), QA: `gemini-qa` (`Hydrogen XHigh`), revisor: `gemini-revisor` (`Neon XHigh`, modo unificado ADR-0026; segundo revisor dispensado por não haver regra financeira, banco ou auth).
- **Status do cartão:** **proposta (aguarda aprovação/merge do dono junto com a ADR-0028).**
- **Depende de (em `main` antes de executar):** PR #29 (ADR-0026), PR #30 (`T2.5` — Shell e tela Entrar) e ADR-0028.
- **Branch:** `equipe-gemini/T2.5b`, a partir de `origin/main`. O dev e o QA fazem commit e push nela. **Quem abre o PR é o revisor** (ADR-0025 / ADR-0026).

### Objetivo

Consolidar toda a base visual compartilhada pelas 6 telas do Meu Financeiro: tokens completos no `@theme` (zero cores hexadecimais no JSX), correção do contorno `:focus-visible` no `<nav>`, cabeçalho completo com status de sincronização e botão `"Sincronizar agora"` no desktop, barra de navegação inferior fixa no celular (`< 640px`), selo reutilizável `SeloConferencia`, faixa discreta `FaixaPrevia` e interfaces de ViewModel em `components/contratos/ui.ts`.

### Contexto mínimo

- **Design de referência:** `docs/design/Main.dc.html` (cabeçalho com área de sincronização), `docs/design/Enviar.dc.html` (barra de navegação inferior mobile), `docs/design/Contas.dc.html` e `docs/design/Revisar.dc.html` (tokens e selos).
- **Achados do PR #30 (Issue #43) corrigidos aqui:**
  1. `overflow-x-auto` no `<nav>` recortava `:focus-visible` (2px + 2px offset);
  2. `pathname ?? '/'` em `NavegacaoAtual.tsx` marcava Painel quando `usePathname()` é nulo — trocar para `pathname ?? ''`.
- **Regra inegociável (ADR-0028):** zero lógica de cálculo financeiro; zero cores `#...` em `.tsx`; `'use client'` apenas em `NavegacaoAtual` (ou wrapper mínimo de pathname para desktop/mobile).

**3. `components/ui/SeloConferencia.tsx` e `components/ui/FaixaPrevia.tsx`**
- `SeloConferencia`: recebe `{ estado: EstadoSelo }`:
  - `confere`: texto `"Confere"`, `-rotate-3`, borda `border-confere`, texto `text-confere`;
  - `verificar`: texto `"Verificar"`, `-rotate-3`, borda `border-aviso`, fundo `bg-aviso-fundo`, texto `text-aviso`;
  - `nao_confere`: texto `"Não confere"`, `-rotate-3`, borda `border-aviso`, texto `text-aviso`;
  - `aguardando`: texto `"Aguardando"`, sem rotação, borda tracejada `border-dashed border-texto-suave`, texto `text-texto-medio`.
- `FaixaPrevia`: faixa discreta com `role="status"` informando `"Prévia visual com dados fictícios. As regras financeiras e conexões reais entram nas próximas etapas."`, opcionalmente aceitando `children` (ex.: controles de demonstração na tela Revisar).

**4. `Navegacao`, `NavegacaoAtual`, `NavegacaoMobile` e `Cabecalho`**
- `Navegacao` (puro): mantém `<nav aria-label="Principal">` com os 4 links (`/`, `/transacoes`, `/contas`, `/importar`), corrige o recorte de `:focus-visible` (folga interna compensada `p-1 -m-1` ou ajuste equivalente sem causar rolagem da página) e continua com alvos `>= 44px`.
- `NavegacaoAtual` (`'use client'`): usa `pathname ?? ''` (nunca `'/'`), repassando para `Navegacao` (desktop `hidden sm:flex`) e/ou `NavegacaoMobile` (`fixed inset-x-0 bottom-0 z-20 flex border-t border-borda bg-superficie sm:hidden`, `min-h-[56px]`, indicador superior azul `shadow-[inset_0_3px_0_0_var(--color-primaria)]` no item ativo, fiel a `Enviar.dc.html`, usando `aria-label="Navegação principal mobile"` para evitar duplicidade de landmark semântica).
- `Cabecalho`: no desktop (`>= 640px`), exibe `Logo` + `Navegacao` + área direita (`statusSincronizacao`, padrão `"Sincronizado hoje, 06:12"`, e botão `"Sincronizar agora"` `min-h-[44px]`, `type="button"`, desabilitado/informativo com `aria-disabled` ou `title` quando em modo prévia). No celular (`< 640px`), exibe `Logo` limpo no topo (pois a navegação fica na barra inferior fixa) e o `<main>` em `app/(app)/layout.tsx` reserva `pb-20 sm:pb-10` para nada ficar encoberto pela barra fixa.
